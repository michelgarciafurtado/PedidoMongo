# PedidoMongo

Projeto de estudo sobre persistencia de dados usando banco não relacional na implementação do MongoDb

## Objetivos
- Adquirir conhecimento teórico sobre banco de dados orientado a documentos;
- Entender como realizar os métodos CRUD em classes com propriedades agregadas;
- Aprender a mapear agregações um-para-muitos, muitos-para-muitos de maneira prática;
- Identificar singularidades na modelagem de domínio para um mapeamento relacional com relação ao mapeamento orientado a documentos;
